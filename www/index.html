Manual setup

  1. Open the extender's admin page in a browser.
  2. Choose Repeater/Client mode and select your Piso WiFi network.
  3. Place it where signal is still strong. Hardware is required; this app cannot boost signal by itself.

Remote SSID/password changes need a router adapter on the backend (none included for your model yet), so the app will say "unsupported" instead of pretending.
